# Web Quality Lab

## Sobre o projeto

Este projeto de portfólio tem como objetivo praticar os fundamentos de Quality Assurance (QA) por meio de testes manuais em uma aplicação web de treinamento.

O foco inicial está na análise das funcionalidades de login, cadastro e formulário de contato, com documentação dos casos de teste, resultados observados e possíveis defeitos.

## Objetivos

- Praticar a elaboração de casos de teste.
- Verificar comportamentos esperados e observados.
- Explorar validações de campos e mensagens apresentadas ao usuário.
- Documentar evidências e possíveis defeitos.
- Desenvolver conhecimentos fundamentais de testes de software.

## Escopo dos testes

- Login: validação dos dados de entrada e mensagens de retorno.
- Cadastro: preenchimento e validação dos campos.
- Contato: validação do formulário e mensagem de envio.

## Metodologia

Os testes serão executados manualmente. Os resultados serão registrados com base no comportamento efetivamente observado, sem presumir defeitos ainda não confirmados.
